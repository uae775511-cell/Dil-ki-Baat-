# Dil-ki-Baat-
Dil Ki Baat ❤️ is a modern and secure matchmaking platform with registration, login, phone OTP verification, user profiles, photo support, profile matching, private 1-to-1 real-time chat, reporting and blocking, membership payments, and a protected admin panel. Built with Next.js, TypeScript, Tailwind, Supabase, Stripe and Twil
